M2 Backup - Privacy policy

M2 Backup is a private tool used only by its owner on a home server.

  • It uses the Google Drive permission "drive.file". It can only see and change files that it created itself. It cannot see any other file in the Drive.
  • It uploads the owner's own backup files, encrypted before upload, to one folder in the owner's own Google Drive.
  • It collects no data about anyone else. It shares no data with anyone. It shows no ads and sells nothing.
  • The sign-in token is kept only on the owner's home server. The owner can remove access at any time at myaccount.google.com/permissions.

Last updated: 16 November 2026.
